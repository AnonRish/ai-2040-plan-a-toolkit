# Claim/evidence discipline

`CLAIM_EVIDENCE_MATRIX.json` makes the promotion boundary explicit. In particular, software success can establish software-level integrity/correctness claims, but it cannot promote a global Track 3 absence claim. That claim requires a defined closed population, independent external evidence, continuous observation and an explicit adversary model.

This matrix is intentionally conservative: it records what a result cannot establish as well as what it can establish.
