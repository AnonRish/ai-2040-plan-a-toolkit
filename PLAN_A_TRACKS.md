# AI 2040 Plan A implementation tracks

This repository is the coordination layer for the four tracks described by
the AI Futures Project verification page:
Track 1 company auditing, Track 2 initial international verification,
Track 3 absence of secret compute, and Track 4 full workload verification.

Source: https://ai-2040.com/supplements/verification-plan/get-involved

Software-complete means reproducible implementation, machine-readable evidence,
adversarial tests, and independently checkable receipts. It does not mean
hardware validation or field validation.

| Track | Software closure | External gate |
|---|---|---|
| 1 | embedded challenge -> evidence chain -> threshold receipt | independent site access, audit authority, pilot |
| 2 | common receipt contract + Frontier Verify recomputation | real GPU/NIC/tap/memory hardware and review |
| 3 | residual accounting + evidence reconciliation | globally closed transaction inventory, intelligence and inspection |
| 4 | workload manifest + artifact/resource/operation verification | frontier-scale recomputation/proofs, hardware roots and review |

Global rule: UNKNOWN, NOT_TESTED and NOT_APPLICABLE never become PASS implicitly.
